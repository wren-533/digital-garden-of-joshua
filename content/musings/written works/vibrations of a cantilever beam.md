Perhaps the magnum opus of all my lab reports for MECE 3360 – Experimental Methods, I take great pride in the writeup I did on our vibrations of a cantilever beam lab. Not because my analysis was especially thoughtful or thorough, or that it helped me gain a better intuitive understanding of vibration analysis (which it did), but because it was the first sizeable document I had typeset completely using $\rm{\LaTeX}$.

See, just a couple of days prior, I had gone down the rabbit hole of figuring out how to set up Visual Studio Code (which I had never used before this point) as a local $\rm{\LaTeX}$ editor. The whole reason for this was that Overleaf has an unfortunate compile time limit for free users, meaning that I wouldn't be able to render all the little figures I needed to. The seemingly endless possibilities presented in Paul Wintz's [article](https://paulwintz.com/latex-in-vscode/) further piqued my desire to move away from Overleaf, but I found it inaccessible since it lacked setup instructions. Davis Cole's [succinct and entertaining video](https://www.youtube.com/watch?v=Mty0vHb0knI) video on setting up VS Code as a $\rm{\LaTeX}$ editor proved immensely helpful, and soon after installing WSL (Windows Subsystem for Linux) and the appropriate plugins, I was off to the races.

I don't think any normal person derives as much pleasure out of typesetting things with $\rm{\LaTeX}$ as I do. Computer Modern, the default font for $\rm{\LaTeX}$, also scratches some deep-seated itch within my brain. I digress...you can read the lab report below if you'd like!
